    Questions

    How is a feature file turned into test cases?

    Each Scenario becomes one test. Its Given, When, Then, And and But lines become test steps. Data tables and docstrings under a step go into the Data column. The Feature name is used as the description and tags become labels.

    What happens to Scenario Outlines?

    By default each row of the Examples table becomes its own test, with the <placeholders> replaced by the values. Untick the option to export the outline once, unchanged.

    Is my data uploaded anywhere?

    No. The conversion runs entirely in your browser and nothing is sent to a server.

    Does it replace Xray's own Gherkin import?

    No. Xray can import feature files as Cucumber tests. This tool is for teams that want plain manual tests with steps, or that use Zephyr, from feature files.

    Is the Zephyr output verified?

    Not yet. It is experimental and follows Zephyr's documented CSV fields. Try a small batch first.

    What are the parser limits?

    One English Feature per file and at most 10,000 expanded tests. Rule-scoped Backgrounds and translated keywords are not supported and block export. Review all warnings: this is a focused converter, not a complete Gherkin validator. Ask about a custom migration pilot if your layout is unsupported.
