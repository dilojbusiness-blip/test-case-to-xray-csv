Test Case Spreadsheet to Xray CSV

Turn a spreadsheet of test cases and steps into a CSV for Xray's Test Case Importer in Jira. Everything runs in your browser. Your file is never uploaded.

Import preflight

Blocking issues disable download; warnings need review. This checks the file structure, not the settings in your Jira instance.

    In Jira: Apps → Xray → Test Case Importer → CSV. Map Test ID, Summary and Test Type, plus the Xray Test Step fields Action, Data and Expected Result. Import each numbered part separately; start with a small sample to verify your instance's mapping.

    Questions

    How do I import test cases from Excel into Xray?

    Save your sheet as CSV (or paste the cells), load it here, match the columns, and download the result. Then open Jira, go to Apps, Xray, Test Case Importer, and choose CSV. Map Test ID, Summary and Test Type, and map Action, Data and Expected Result to the Xray test step fields.

    What should my spreadsheet look like?

    One row per step. Put the test name on the first row of each test and leave it blank on the following step rows. Repeating a name on a later row starts a new test, even if the name is the same. Columns can be in any order and named anything; you pick them in step 2.

    Is my data uploaded anywhere?

    No. The conversion runs entirely in your browser and nothing is sent to a server. Do not paste anything your company forbids you from handling outside approved tools.

    Does it work with Zephyr?

    There is an experimental Zephyr Scale output (Name, Objective, Priority, Labels, Step, Test Data, Expected Result). It has not been tested against a real Zephyr import yet. In Zephyr's wizard you map the columns yourself, and steps for one test are written on consecutive rows. Please try a small batch first.

    Can I upload an .xlsx file?

    Yes, the first sheet of a modern .xlsx file is read in your browser. Old .xls files are not supported; save them as .xlsx or CSV first.
