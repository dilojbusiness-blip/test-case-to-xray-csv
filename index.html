Test Case Spreadsheet to Xray CSV

Turn a spreadsheet of test cases and steps into a CSV for Xray's Test Case Importer in Jira. Everything runs in your browser. Your file is never uploaded.

1. Load your file

In Excel, use File → Save As → CSV first. Or paste cells copied from Excel or Google Sheets:

2. Match your columns

Columns were guessed from the header names. Fix any that are wrong. Rows with a blank test name continue the test above them.

3. Check and download

    In Jira: Apps → Xray → Test Case Importer → CSV. Map Test ID, Summary and Test Type, plus the Xray Test Step fields Action, Data and Expected Result. Xray imports up to 1000 issues per run.

    Questions

    How do I import test cases from Excel into Xray?

    Save your sheet as CSV (or paste the cells), load it here, match the columns, and download the result. Then open Jira, go to Apps, Xray, Test Case Importer, and choose CSV. Map Test ID, Summary and Test Type, and map Action, Data and Expected Result to the Xray test step fields.

    What should my spreadsheet look like?

    One row per step. Put the test name on the first row of each test and leave it blank on the following step rows. Columns can be in any order and named anything; you pick them in step 2.

    Is my data uploaded anywhere?

    No. The conversion runs entirely in your browser and nothing is sent to a server. Do not paste anything your company forbids you from handling outside approved tools.

    Does it work with Zephyr?

    Not yet. The output follows Xray's Test Case Importer layout only.
